# 奇门符头、值使与寄宫的规则选择

2026-09-19，适用于 `zhuanpan-qimen-chai-bu-v1`。完整来源、版本、独立差分结果见 [divination-research.md](../validation/divination-research.md)。

- 日柱回推最近的甲/己日，构成五日符头组。符头支为子午卯酉取上元，寅申巳亥中元，辰戌丑未下元。交节切换节气用局表，不重置符头，不使用旧 PRD 的逐日干上中下循环。
- 戊起局数宫。阳顺1至9、阴逆9至1。阴二局的戊在2，不在8。
- 旬首六仪所临原始宫定值符星和值使门。甲时用本旬所遁六仪定位。
- 值符加时干；值使从原宫按本旬经过时辰数沿九宫阳顺阴逆计数。然后八门在外圈整体旋转，保留休生伤杜景死惊开的相邻关系。
- 固定中五寄坤二，天禽/中仪跟随天芮；值使须先从原始中五完成计时，再对最终中五寄宫，不能提前从坤二起数。分寄/置闰/飞盘不混入这个版本。
- 节气使用真实瞬间；真太阳时只改变日时钟面，不把交节天文瞬间随城市平移。

来源不是只有旧测试：

1. [《烟波钓叟歌》](https://zh.wikisource.org/wiki/煙波釣叟歌) 的五日一元、符上之门为直使、值符加时干、值使顺逆计宫。此传本含超神接气语境，不单独证明现代拆补法全部细节。
2. [qfdk/qimen](https://github.com/qfdk/qimen/tree/a32544aa24bd9c7d8e3d24aa456085d5533edafb/lib) 的独立地盘/星盘/门盘纯函数；18/1080/960组对照一致，其自身完整日期 fixture 有交节错误，未采用。
3. [qimen-go](https://github.com/deminzhang/qimen-go/blob/4d3f58fa0f401b5b3a337f119138e99e90685dda/xuan/qimen.go) 的独立三元公式、阴遁戊起本局、值使飞数及固定寄二分支。历法来自6tail，与我们的日历并非独立，所以只用于排局算法互校。

未取得《御定奇门宝鉴》的可核验具体卷页，本笔记不伪造该书的文本证据。不把这套明确规则说成排除所有其他传承的唯一权威。
