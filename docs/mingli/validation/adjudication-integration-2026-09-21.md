## 保存、问答与解释依据

- 本命结果绑定账号出生资料和引擎版本；四余、命度和七曜一起建档，问答读取档案。派生一致性校验不重新调用星历。
- 六爻、奇门补问沿用原始起盘时间及原爻、原宫位；只更新问题相关推断，保留原记录及补充记录。
- 完整回执采用可逆字典保存重复字段、规则路径、值与日期。原文、空数组、false、对象身份和候选顺序均保留。畸形字典、越界引用、丢失字典不能降级为可信旧格式。
- 较大卦盘的固定 `ruleSources` 完整原文在同次请求中独立发送，工具回执按调用编号、工具名和内容 SHA256 引用。目录须早于对应调用；错绑、缺失、篡改或跨轮引用均不能用于核验。写作、复核与重试都保留目录，保存到本地的回执仍自带完整来源。
- 大型复核请求的字段索引以字符串前缀节点和数字序列保存全部调用身份、字段名和原始指针，值从同轮完整工具读取。原生与独立 JavaScript 解码器分别对照完整事实；同名字段的不同指针不合并。未提高后端容量限制，也未删除来源或条件。
- 各层先还原再检查规则、展示盘面或验证引用。原始 JSON 指针在完整还原结果上解释，不能把压缩索引当爻位或传统结论。
- 导入备份只恢复可读历史，不恢复外部文件中的计算信任。本轮同时修正原盘补问回执不能导出的旧限制。
