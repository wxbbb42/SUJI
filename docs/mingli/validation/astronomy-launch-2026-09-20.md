# 新模块上线与六爻 B5b 验收

本批交付七曜星位与中国二十八宿现代首星参照，验收六爻三合的结构、证据绑定及完整传输。用户已授权进入扩展上线，原先“先完成全部核心再扩展”的顺序不再阻挡本批；这不代表所有自动论命/断卦规则已完整。

## 用户能使用的内容

- 登录并确认出生资料后，保留原八字紫微建档，另建账户隔离的天文本命档案。有效档案重启后可复用，普通问答不重复计算星历。
- 「我的 → 出生星历」显示日月水金火木土的地心黄经黄纬、赤经赤纬；显示出生月亮所在宿、入宿角度、宿宽、距最近宿界的角度，以及计算口径和来源。
- 模型工具 `get_natal_astronomy` 只读已验证的固定本命，可选一颗七曜或全部。模型不能传入自己的出生资料、任意日期或缓存；工具结果有原始JSON指针对应的证据索引。
- 模块名称不使用完整“七政四余”，不提供四余、十二宫、命度、古度、宿曜关系或生肖。现代赤经宿位不能冒充这些能力。

## 计算与资料依据

出生钟面仍按固定 UTC+8 解释，1901–2100；不应用历史夏令时，也不加八字真太阳时偏移。保存UTC、近似UT1、TT及Espenak–Meeus ΔT政策。没有给缺失纬度填默认值，地心计算本身无需纬度。

七曜使用固定 Astronomy Engine 2.1.19（MIT）。独立 Swiss/Moshier研究保留5,600组季度比较：默认时标13组未来月亮样本超预设60角秒，最大74.0525角秒；共同TT控制最大21.4853角秒。该对比说明时间模型差异，不能把共同TT结果当作未来UTC物理精度或全部时刻误差上界。月亮GeoMoon与其余天体的光行时/光行差口径分别标注。

28颗距星身份逐项对照固定版本Stellarium现代首星I索引，并以Hipparcos J1991.25 ICRS和SIMBAD核对。明确选择 `contemporary-first-star28-equatorial-v1`，不声称统一历史距星流派。奎ηAnd/旧ζAnd、斗φSgr/另表μSgr、觜参新旧星的差异保留。来源许可与署名随App分发；档案见 `validation/research-qizheng/catalogue/ATTRIBUTION.md`。

距星变换采用切向自行、日期岁差及简化章动，不含周年光行差、视差、偏折、透视加速度及ICRS框架偏差。84组ERFA独立变换最大差0.13605角秒；保留最初0.1角秒筛选失败，0.2角秒只是该抽样回归阈值。宿界先验证单圈有序，再建立非等分、左闭右开的区间；旧觜参反序反例必须被拒绝。出生时间精度未知、星历/星表统一误差上界未知，所以给出参考宿位与距离，不承诺绝不跨界。

## 六爻验收与实际修复

三合范围是可见原爻、单个实际动爻配日月、内初三/外四六的实际端点动变；不混入伏神、静态变卦投影或任意跨范围成员。四组三合表、重复身份、缺支、中神和原条件均保留。4096组独立结构复算、古例及Swift伪造反例通过；完整效力判断仍受电子古籍异文与条件缺口约束。

完整回执使旧请求容量暴露真实回归：48组中42组超120,000 UTF-16，总量最大127,398。修复采用可逆的重复字段布局与按实际编码大小分批，未删事实或提高服务端限制。最终48/48真实 Core→ChatClient→backend validator 通过；独立解码逐字段恢复96份盘面及全部事实ID、值、指针。最大总111,399 UTF-16、单消息30,872、请求168,290 bytes。完整报告、初始失败和复跑脚本见 `validation/reasoning/b5b-launch-acceptance/`。

## 原生生命周期与独立审查

旁路绑定账户、完整BirthProfile、实际bundle哈希、嵌入源码哈希、模块政策与摘要。并发请求合并；资料变化、损坏、导入、删除及账户切换触发校验或失效。天文失败不阻断旧八字紫微资料页。

审查发现一个真实竞态：已取消且元数据已热的排队任务可能通过磁盘缓存命中重新发布旧档案。修复在任务入口和缓存发布前检查取消/账户范围/出生资料；旧实现实跑2个断言失败，恢复修复后6项生命周期测试通过。另修复验收探针硬编码临时路径，并更新过时的策略契约。

全套星名数据由资料任务核定，控制代理复跑28项身份检查；不同审阅任务检查生产数学、缓存契约、六爻结构和传输实现。报告不把资料作者复查自己的数据称为独立来源验证。3张模拟器截图已逐张检查：星位、宿位与计算依据可读。

## 是否可以开始产品体验优化

可以开始现有能力范围内的产品体验优化：输入确认、账户建档、来源查看、原盘重试/补充问题和星位展示已有明确契约与回归证据。基础层当前更可核验，不能称为完整“自动命理大师”。以下能力继续保留为独立算法目标，界面不得暗示已经完成：

1. 六爻自动取用、综合旺衰与三合/墓绝最终效力，以及由此推出事件结果；三合成员齐全本身不证明成局有效。
2. 奇门完整应期（E2b）及综合断事；现有条件候选不是确定日期。
3. 八字强弱/用神工程权重与传统格局解释的完整裁定，以及模型自然语言逐项忠实表达。既有已知解释缺口继续按原验证计划处理。
4. 四余历元和公式、宫位、命度、古度与流限；全球历史时区和未知出生时间输入模型。

后续产品工作应围绕“用户清楚输入、结果对象、依据与下一步”，不用增加一个总分掩盖上述不同成熟度。
