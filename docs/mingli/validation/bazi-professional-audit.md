# 八字非历法规则独立审计

审计日期：2026-09-20。起点：`805683f`。范围：十神、十二长生、藏干身份、干支关系、格局成败救应，以及 InsightEngine / SiLing / multiSchoolVote 的实际调用情况。历法与公开人物传记由另一条审计覆盖；本报告的两例是有真实公历日期的合成测试资料，不是核实过人生事件的真人命例。

结论：发现并修复了两处可复现的柱位身份丢失。它们属于确定的程序错误，不能用“流派不同”解释。基础身份表在此次独立核对的范围内一致；格局与旺衰仍只是有限的工程候选规则，尚不足以称为完整的传统命理判断器。

## 确定错误一：财格扫描误删其他柱的同名比肩

- 输入：`1984-04-20T00:30:00+08:00`，男，不传经度（关闭真太阳时修正）。四柱：**甲子、戊辰、甲申、甲子**。
- 原输出：偏财格候选，`chengBai=cheng`、`jibie=zhong`、`jiuYing=null`。
- 原因：`scanJiShenTransparent` 以 `g === dayGan` 排除“日主”，实际排除了年干甲与时干甲。该函数自己的财格忌神表含比肩，但比肩在所有非日柱都无法进入扫描。
- 修复：只按 `position === 2` 排除日柱本人，年/月/时的同名干仍按比肩进入规则。
- 新输出：`chengBai=po`、`jibie=xia`，继续保留 `assessmentStatus=heuristic-candidate`。这里的 `po/xia` 是既有工程矩阵重新算出的标签，不是本审计替传统全局辨析作出“必然破格/命运下等”的裁定。
- 独立测试：真实日期一例、年/月/时各一例、仅日干同名的正对照、相邻乙庚合忌候选的正对照。先得到 4 个断言失败，再修复。

传统依据不是“只要见比肩就必破格”。《子平真诠评注》[论用神格局高低](../source-texts/bazi/ziping-zhenquan/00-abstract-chapters.md) 第 152 行原文含“**财格忌比劫争财**”，并紧接乙庚相合、以忌制忌的例外；第 108 行“**财逢劫而透食以化之，生官以制之**”更说明必须继续查救应。本修复处理的是实际比肩不得消失，不把“比劫”简化成一律凶断。

## 确定错误二：一个柱位获救，被复用为同名干全部获救

- 输入：`1993-06-08T13:30:00+08:00`，男，不传经度。四柱：**癸酉、戊午、庚申、癸未**。
- 原输出：正官格候选，`chengBai=jiuying`，4 条救应。月戊对年癸的相邻五合/相克路径，被重复复制到时癸。
- 原因：`scanJiuYing` 原来的相邻函数按干名寻找“任意位置有这一对”，最终 `.every` 又只比较 `triggerGan`。于是 `[0 年癸, 1 月戊]` 的有效几何关系也被错误用于 `[3 时癸, 1 月戊]`。
- 修复：忌神内部传递 `{gan, position}`；每条救应新增可选 `triggerPosition`、`remedyPosition`，按具体柱位判断相邻与覆盖。保留同一处可以存在多个候选规则，不改变既有远合流派边界。
- 新输出：仍保留年癸的 2 条候选，均为 `triggerPosition=0`、`remedyPosition=1`；时癸没有被错误覆盖，因此工程状态变为 `po/xia`。旧 `triggerGan`、文本与字段结构保留，新字段可选，旧数据可继续解码。
- 独立测试：真实日期、只有年癸的积极控制（仍为 `jiuying`，两条不同规则都保留）、只有时癸的消极控制（无救应）。先得到 2 个断言失败，再修复。

这首先是对当前程序“只扫描相邻路径”契约的违反，无须先证明传统上远合是否一概无效。《子平真诠评注》`00-abstract-chapters.md` 第 142 行明言须考虑“**位置之配合次序**”；第 182 行“**若丁火通根，则合之不去，为病不净**”，第 220 行进一步讨论相神受伤，说明真正传统救应比本次位置修复更复杂。位置修复不能替代那些尚未建模的条件。

两例完整前后输出见 [bazi-professional-probes.json](./bazi-professional-probes.json)。

## 成败救应仍不能声称完整的具体原因

1. `XIANGSHEN_DEFAULT` / `JISHEN_DEFAULT` 是固定映射，难表达同一元素依身强、季候、根气与配置转为喜忌。《子平真诠评注》`00-abstract-chapters.md:198` 有“略见财则以财损印为用”等反例。
2. 目前 `scanJiuYing` 只覆盖少量透干路径；第 108 行的“财逢劫而透食以化之”、第 220 行的“会合解冲”“相神被伤”，尚无完整图式与逐层撤销机制。
3. `rankGeJu` 依候选成败、相神是否出现、根力档和忌神数量返回上中下，未求解第 142 行的进退气、位置与有情有力。纸本/转录文献不能为这些数字阈值自动背书。
4. 完整三合身份不等于成化成立，专旺/从格/化气候选的筛查也不等于古籍全局求解。目前保留 candidate 与条件说明是必要的真实边界。
