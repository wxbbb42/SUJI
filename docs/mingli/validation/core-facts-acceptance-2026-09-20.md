# 核心补齐 A 批：本变伏状态与奇门时空事实

基线：`a91a6b1`。这是[核心补齐计划](../../superpowers/plans/2026-09-20-core-mingli-completion.md)的第一批，不是四体系自动论命、断卦已经完整的结论。

## 已实现

- 六爻每个本爻、实际动爻的变爻、纯宫伏神都有独立 `context`：旬空；月/日干支、五行、临值、生克方向、冲与合；月建五行标签。旧本爻布尔字段从同一 context 生成，避免两套结果。月破与临日、合与克可并存，未压成吉凶分数。
- 奇门 `hourVoid` 明确时旬、实际空支、所属宫及本宫支位覆盖。`partial/full` 是支位数量说明，不是整宫效力判决。`horse` 明确按时支取时马，不混入日马。
- 奇门各外宫 `doorRelation` 区分门克宫、宫克门、生与比和；本版只将门克宫标为门迫。中五无门，不补造门迫。
- `starSeason` 使用所选九星月令表；真实寄宫另有 `hostedStarSeason`，中五静态参考不重复计天禽。月柱取真实物理交节时刻，即使日时采用显式太阳钟面也不改变月令。
- 两个工具返回 `ruleSources`，包含规则版本、引用定位、出处等级和边界。原生事实索引补入月日柱、用神候选、方法、本变伏状态、奇门新增事实和返回的来源元数据，按对象精确绑定指针。
