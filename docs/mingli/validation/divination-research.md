# 紫微、六爻、奇门：独立来源研究与验证

研究日期：2026-09-19。基线：`df1a7c9`。本报告检验历法、传统规则的一致性及软件实现，不声称命理具有预测现实事件的科学有效性。

## 结论与已实施范围

原实现不能称作完整可靠排盘。已取得可重复的证据：阴遁地盘 9 局中 8 局起宫错误；108 个甲时/局/旬组合有 84 个未伏吟；连续 60 日三元有 40 个与拆补符头法不符；八门错误绑定开门和值符；同一物理时刻的节气随经度变化；六爻月柱使用公历月且时柱恒为未；紫微晚子时、农历出生时间身份和四化字符串存在错误。

本次修复选定明确规则并提供结构化依据：

- 紫微采用 iztro 2.5.8 默认安星表，子初 23 点换日，农历正月换年，闰月前十五日当月、后十五日次月。修正晚子索引 12、真实公历出生时间、四化的“化”前缀、无效日期与库全局配置污染。
- 六爻采用京房八宫纳甲、北京时间日时、精确交节月柱、子初换日；补足可重放六爻原值、世应、纳甲、六神、旬空、伏神、动爻变爻六亲、月破日冲日合。变爻六亲仍以本卦宫五行为基准。通行卦序与八宫数组序号分开。
- 奇门采用时家转盘拆补法；五日甲己符头地支定元，真实物理时刻定节气；阴阳遁均戊起局数宫；甲时以本旬所遁六仪定位；值使从旬首原宫按旬内时数沿九宫阳顺阴逆飞数，随后八门整体旋转。采用中五固定寄坤二、天禽随天芮；保留中五原宫和寄干实际落宫，便于复核。
- 不再将固定“1–2 周”或“1–3 月”输出成应期。保留应期字段，明确尚缺取用、动静、空亡和事件条件。月建/宫位的五行关系是局部事实，不包装为完整旺衰、吉凶或预测概率。

这些修复提升可核对的排盘基础；完整断法、所有流派与预测有效性并未因此获证。

## 典籍与专业资料：实际读到的依据

## 旧 PRD 的纠偏与奇门方法决策

旧 `2026-05-11-qimen-accuracy-hardening-prd.md` 推荐“甲己上、乙庚中、丙辛下、丁壬上、戊癸中”。这与五日一元冲突。例如甲戌是下元符头，随后乙亥、丙子、丁丑、戊寅仍属该下元；不是甲必上元。也不是每次交节都从甲子/上元重新计数。旧 PRD 自身要求源审查优先，因此本次不执行错误映射。

选定拆补政策：日柱回推最近甲或己日为符头；子午卯酉上元、寅申巳亥中元、辰戌丑未下元。甲子序号 `n` 下独立 Go 实现等价于 `floor((n % 15)/5)`；本项目按符头语义实现，两种算法对完整 60 日一致。交节精确瞬间切换节气的三元局数表，符头五日组继续进行。此法与置闰/超神接气的接补规则不同，未混用。

寄宫有固定坤二、阴阳分寄、四维寄宫等传承。SUJI 旧代码阳寄二阴寄八，但未给可读的明确定本；qimen-go 的可选二八寄法还相反（阳八阴二），不应将其中之一硬称“唯一正确”。本次默认固定坤二，与 qfdk 模块和 qimen-go 固定寄二模式一致。天禽与中宫仪随天芮一起走，单独记录寄干字段；值使原始中五先完成九宫计数再寄宫，不能先从二宫计步。

八门外圈的顺序保持休生伤杜景死惊开。阴遁反的是九宫计步和八神排布方向，不把整组门的相邻关系翻转。

取用层与排盘层分开：旧分类把庚固定叫“官星”、男女婚姻都选庚、以天蓬作病气等，没有给出可复核的奇门取用规则，已撤去。现在只展示“日干求问者、时干所问之事”的常见时家参考口径，以及开门事业、生门财务、六合关系、天芮病象的候选位置；甲干按其本身旬仪定位，保留原干身份。结构化 `references` 和 `selectionStatus: initial-reference` 明示这不是最终用神裁定。父母、子女没有足够对象资料时不虚构固定星干。此层属于明确标注的产品初始取象口径，尚未逐项绑定原典卷页，不能把上述盘面模块的开源差分通过数冒充取用或预测有效性验证。

## 独立实验结果与覆盖边界

### 六爻

- `bopo/najia` 纯函数输出全部 64 卦宫属、世应、六爻纳甲与六亲；新引擎逐项 64/64 一致。日历不借用其 cnlunar，所以独立性只覆盖纳甲/八宫规则。
- 穷举 4^6 = 4096 组 6/7/8/9 输入，验证原值保存、动爻与变卦翻转；不是用随机100次充当确定性验证。
- 另有本卦宫定变爻六亲、伏神、日旬空、六神、精确节月时柱、无效投币输入的固定例。
- 不宣称完成所有用神断法、进退神/化墓化绝/三合/反吟伏吟/应期的完整解释体系。已有结构化事实足以支持下一阶段可审阅推理，但模型不能补造缺失字段。

### 紫微

- 在隔离 Node VM 执行 2020 年独立表驱动 ZiWeiDouShu，10 年各12时，共120张盘；108张普通月主星盘全部一致。
- 剩余12张来自1987-08-15（农历闰六月廿一），6张产生主星差异。旧库按原六月，新库半月法按七月，差异完整保留，不能隐藏为“120/120”。仅普通月108盘固定为 regression oracle。
- 《全书》卷二手工计数规则对12个月×12时辰=144组身命位置一致；十干四化、子初跨日、农历闰月身份、无效日期、全局规则污染另测。
- 亮度、所有杂曜、大限/流月飞化、年界附近、跨时区出生资料仍需要更大的独立 fixture 集；本轮不能仅用 iztro 与自身的 parity 宣称全面验证。

### 奇门

- 与 qfdk 的独立纯模块比较：18地盘、1080星盘、960八门盘，全部一致，摘要和5张完整门盘写 `qimen-results.json`。
- 其 bamen API 不支持旬首原宫中五的120组，明确排除；本项目独立回归覆盖阳/阴五局乙时原宫5分别计至6/4再寄宫，不借错误的提前寄宫算法。
- `qfdk/qimen/test/paipan.test.js` 将2026-06-05 16:52标作芒种阳六局，但独立精确历法给芒种23:48:21 +08。该整盘 fixture 被拒绝，未进入 SUJI；这是不依星数盲信开源库的实际例证。
- 古典/独立公式覆盖60日三元与108甲时伏吟。精确节气来自统一 calendrical facade，独立天文对照与范围请同时阅读 calendar 研究报告。
- 未覆盖所有格局、置闰飞盘、暗干流派、择日与应期规则；“standard”只说明这套明确盘法已实现，不等于所有术数解释已经权威验证。
