# 香港天文台1901–2100逐日公农历对照

## 结果

2026-09-19 对香港天文台1901–2100年公开公农历表逐日核对：**73,049天均有官方日期序列依据，73,000天可比较完整农历年、月、闰月与日**。仅发现此前已知的 **2057-09-28至2057-10-27，共30天** 分歧；生产转换无异常。其余已建立的字段一致。

这次 oracle 是独立提取的香港天文台官方表格；被测方才是生产 `lunar-javascript@1.7.7` 经固定北京时间 facade 的输出，不再把同一个库的两次调用当作独立验证。

| 覆盖项 | 实际结果 |
|---|---:|
| 请求官方年度PDF | 200份，仅1901–2100 |
| PDF下载成功 | 200份 |
| PDF字框解析成功 | 198份 |
| PDF失败后使用同年官方TXT | 2份：2048、2051 |
| 最终仍缺失的年度来源 | 0份 |

| 跨月/跨年序列验证错误 | 0 |
| 生产转换异常 | 0 |

1901年表开头是上一农历年的月中，只印日数，不印该段月份或闰月标志。1月21日起能读到“12th Lunar Month”，但其前面的完整月序仍不可见；直到2月19日正月初一后，年月及闰月状态才全部由官方序列确立。脚本把之前未建立字段保留为 `null`，没有使用被测库补值。49天的日数仍全部参与比较，因此不能把“73,049天有日序对照”写成“73,049天所有农历字段完整独立验证”。

## 来源失败与恢复

- 首轮8份PDF未通过严格解析。1948/1979页脚出现额外“May”；2023/2028/2078/2096有“Lunar”断成“Luna/r”或“Month”裁切。以月名称的实际列定位行，并重组断词后恢复6份。原始失败逐份保存在 [恢复记录](../../../native/Engine/validation/research-calendar/hko-parser-recovery.json)。
- **2048**：Poppler `pdftotext 26.04.0 -bbox-layout` 报 `std::out_of_range: basic_string`；普通布局抽取没有可用正文。使用 [官方2048文本表](https://www.hko.gov.hk/en/gts/time/calendar/text/files/T2048e.txt)，记录PDF哈希、具体失败、TXT网址与哈希。已实际测试删除字框缓存后的失败回退。
- **2051**：PDF的9月30日位置未抽出日期值；布局文本同样只列9月1日至29日，不能猜填。使用 [官方2051文本表](https://www.hko.gov.hk/en/gts/time/calendar/text/files/T2051e.txt)，其 `2051/9/30` 明确为农历26。回退仍是独立官方来源，不使用生产库。

完整200份文件的URL、字节数、PDF/抽取文本SHA256、解析状态和具体失败，见 [来源清单](../../../native/Engine/validation/research-calendar/hko-daily-manifest.json)。PDF、字框HTML与提取日序缓存在 `hko-cache/`，由本目录 `.gitignore` 排除；仓库保留脚本与约160KB的清单/结果，不提交整批PDF。

## 可重复方法

从仓库根目录运行：

```sh
python3 native/Engine/validation/research-calendar/hko-daily-audit.py
node native/Engine/validation/research-calendar/hko-daily-compare.mjs
```

需要 `curl`、Poppler `pdftotext`、Python 3，以及现有Engine的Node依赖。下载并发默认为6，上限8，只允许1901–2100共200个年度PDF。缓存命中时不会重下；`--refresh` 可重取官方表，年份子区间可用 `--start` / `--end`。脚本没有读取生产库来构造官方序列。

解析首先用PDF字框中的31个公历表头建立列坐标，再读取12个月行中的日期或带序数的月初标记；逐个检查单元格是否唯一、当月天数是否完整、公历是否连续、农历日序是否只在29/30后回到1、跨年月份是否连续。闰月只能由官方序列中重复的月号推导。最终以北京时间正午调用生产calendar facade，比较已建立字段；保存全部分歧，而非只留首个例子。

这是公农历**日期**对照，不验证历史出生地时区/DST、子初换日时刻、交节秒数、四柱取法、格局解释或现实预测能力。对未来极近午夜的朔时，官方日期表本身也是一种公开参考，不能从一致天数推导命理模型“准确率”。
