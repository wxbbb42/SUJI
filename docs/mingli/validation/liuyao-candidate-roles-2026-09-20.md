# 六爻候选对象的元忌仇：B3

本批补齐相对于具体候选对象的元神、忌神、仇神结构，并接入原生六爻依据报告。它不裁定用神、角色最终施力、救应成功、事件吉凶或日期。

## 规则依据与边界

读取《增删卜易》第九、十章 raw 子页面，使用 onlyinclude 正文，排除后附现代“原劍按”。原文、URL、SHA256 在 `native/Engine/validation/research-divination/liuyao-role-sources.json`。第九章定义元生用、忌克用、仇克元生忌；第十章大过之鼎保留目标月破日克，是“元忌同动即有救”的反例。电子转录尚未经影印定本校勘；第十章“忌神動化回頭生扶退神”等疑文未被改写为效力规则。

- 原爻、伏神候选保留全部 ID、对象路径和自己的 context；只在五行相同的候选间共享角色位置。月日候选明确标记不适用此层；无候选时不默认取世。
- 角色只来自六个实际原爻。静爻有结构身份，明动事实另列；依附变爻、完整变卦投影、伏神和日月不充当跨位自由施力者。
- 全部实际元忌、忌仇共同明动配对保留。忌生元、元生用与忌克用并存；仇的五行可以成立，但盘中没有元神爻时不能捏造元神对象。
- 每个候选的空破、生克条件单独保留；角色爻引用自己的日月空破、同位回头关系和完整进退条件。目标受生能力、角色效力、合住、墓绝、事件方向未裁定；只有实际静爻日冲才列暗动未决，不对全动卦添加暗动说法。
- 原生报告独立核对五行字面表、角色完整成员、候选覆盖、明动配对及固定来源 URL/hash。错误对象、遗漏角色、伪造链或来源不给出伪解读；旧版完整回执仍可读。

## 测试与传输

永久测试先观察缺失实现失败，再核验五行手写表、辰月戊申乾→小畜、巳月乙未大过→鼎、酉月辛亥兑→解、静姤伏神和静乾。古例只使用传统月支／日干支坐标，测试时刻及其他柱为合成值，不编造古例公历日期。原文手写 oracle 与生产代码分开保存。

新增字段使旧大盘回归实际超出32,000 UTF16单消息及60,000 byte合并传输限制。修复只对大于600 bytes且与**同一调用**参数严格相等的 question 使用 `questionFromArguments` 引用；原问题仍在工具调用参数，所有盘面事实不变，持久化回执完整。错误调用、不同问题、缺少原参数不授权引用；重试使用同一原卦。无需调整本地或后端上限。

容量验证包括9,728个高容量盘面组合的逐字段还原，以及12个高容量样本的真实 Swift 编排、重试、完整事实索引和后端请求校验。记录在 `b3-capacity-report.json`、`b3-native-capacity-provider-report.json`。原生最大单工具31,094 UTF16、合计52,603 bytes；核验请求包含工具参数后最大107,617 UTF16，均低于既有上限。实际 ChatClient 使用本地 URLProtocol 捕获请求并送后端 validator，不访问供应商，不是部署后端到端试验。

复现：先运行 `b3-capacity-probe.cjs`；将 `b3-native-capacity.swift` 与 `native/Core/Sources/SujiCore/*.swift` 用 `swiftc -parse-as-library` 一起编译运行；再运行 `b3-provider-probe.mjs`。`b3-wire-capture.swift` 用相同方式编译，可指定0–11样本捕获真实 ChatClient wire。脚本均在 `native/Engine/validation/research-divination/`；中间数据写入 /tmp，不含真实用户资料。

最终本地720项Engine／313项Swift Core测试通过，包含20组Node／JavaScriptCore对照；类型检查、资源构建、native-only和diff检查通过。来源索引51条来源／65条声明通过校验。独立审查无阻断性发现：40,960引擎起卦组合、1,280实际原生记录、617,780条引用全部一致；26种畸形变异全部拒收；5组独立古例、日月候选、长问题认证与重试保留原卦均通过。有效原生计数为1,280；最初5,376循环因审查脚本假定固定日期必有日月候选而退出，未作为通过证据。详见b3-review-report.md及独立JSON记录。提交`b20b03ce41585042c69cbe1ea5924d5f19e7b3c0`与远端一致；[run35503491952](https://github.com/wxbbb42/SUJI/actions/runs/35503491952)的engine、swift-core、native-app全部通过。三合、反吟伏吟、墓绝具体规则、综合效力以及其他核心E/F/G缺口仍开放；没有新增七政四余、星宿或生肖。
