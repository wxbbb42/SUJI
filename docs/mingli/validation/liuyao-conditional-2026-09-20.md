# 六爻条件作用链验收（B）

本批补回头生克、飞伏、所选七组进退、静爻日冲的条件证据，不将结构关系判成最终效力、吉凶或应期。完整取用与解读验收仍在核心计划 E/F，综合旺衰、墓绝等不能由本批冒充完成。

## 依据与独立复算

读取《增删卜易》电子本日辰、暗动、飞伏、进退章节；实际正文位置、摘录和 SHA-256 见 `native/Engine/validation/research-divination/core-rule-sources.json`。进退采用该本列出的亥子、寅卯、巳午、申酉、丑辰、辰未、未戌七组，不加入未列的戌丑。正文古例并未给出可核实的公历年代，测试只使用传统月日坐标，不拟造真实人物或事件准确率。

独立期望包括：

- 申月戊午日遯→姤：世午临日与变亥受申生同时成立，亥水回头克同位午火，不推广成所有变爻任意作用原爻。
- 恒五爻申→酉为进，甲戌日、卯月的酉同时旬空月破，仍保留进的结构，效力待条件裁定。
- 姤二亥飞生寅伏、遯初辰飞克子伏，方向和飞伏身份不交换。
- 寅月己未坤→师：第四爻丑土受寅木克，同时有未土日扶及第二动爻巳火生；己未属甲寅旬，子丑空，须保留冲空分支。不能只按月克判日破。
- 静爻日冲的暗动/日破为候选，明动爻不混入静爻暗动；相反条件可共存，综合力量不填虚构分数。

常规测试穷举 4,096 种爻值数组，以独立五行方向矩阵核对 12,288 个回头关系和 3,584 个飞伏关系。固定七组进退有正反及未列配对测试；条件指针和同位共享条件均可解析。独立复核发现否定的“无其他动爻生扶”缺检查集合，已补 `/changingYao` 和被检查动爻的实际属性，静卦与有动而不生的反例通过。

## 原生证据与容量修复

原生仅索引允许的规则字段、条件 ID 和状态，不把任意附加文字当事实。全部工具记录保存完整值。核验索引以同工具同对象的公共键和 JSON 指针前缀压缩，完整键可逐字拼接恢复；反馈仍须用原完整身份通过本地核对。

真实 JavaScriptCore 的姤和全动大畜 `[9,9,9,6,6,9]` 各与奇门合用，原始输出分别 42,710 / 48,543 UTF-8 字节。原核验大畜请求达到 132,867 UTF-16 单位，超过后端 120,000 限额；去重后的完整请求为 110,541（13条），姤为 97,918（12条）。单条 32,000、总消息120条、请求262,144字节均验证，后端限额未增加。

实际 ToolOrchestrator→receipt→ReadingPrompt.history→重试发现原 40KB 重放限额小于首次 60KB 交付限额，导致丢掉第二张盘。现在重放与首次共享既有 60KB 盘面预算，对话文字预算仍40KB。测试验证完整结果相等、两盘证据均恢复、重试不重新起盘。四领域和紫微时间层旧容量测试继续通过。
