## 已选定的确定分支

### 取用与局部日月条件

| 条件 | 本轮裁定 | 保留的反证或边界 |
|---|---|---|
| 明确关系、明确事件、既有类别映射无冲突，符合对象仅一个 | `selected`，指向该原爻或伏神 | 定用与伏神能否出分开；未知关系、代占视角冲突不猜测 |
| 原卦无所需六亲，而日/月有该六亲 | 日月层先于伏神；一个为 `calendar-reference`，两个保持多候选 | 不武断让月胜日，也不把日月当六个爻中的施力对象 |
| 两个以上同类原候选 | `multiple-candidates` | 不以数组顺序、空破、动静固定排序；后面的两现研究说明其原因 |
| 日月生或同类，同时没有克／月冲 | `calendarStrength: supported` | 仅局部支持，不叫全局旺 |
| 日月同时有支持与克／月冲 | `balanced` | 不使用“生七克三”或加权分数 |
| 月破且日克 | `rootless-condition`；没有本位回头生／飞神生这一额外竞争时，效力为 `rootless` | 大过之鼎表明即使元忌实际同动、生链存在，也不能自动复活这个目标 |

`vitality: supported-unopposed` 是本轮的充分条件剖面：有日月直接支持，且没有日月克／月冲、其他实际原动爻的克合冲、本位回头克合冲、伏神的飞克、日月合或静爻日冲待审。它不等价于所有传统旺相情形。明动来源即使自身衰弱也不会被悄悄丢弃；其效力尚未确定时，保留为竞争条件。

`opposed-unrescued` 只在没有日月支持、有克／月冲、且没有实际明动／本位回头／飞神的潜在生扶时成立。其余生克共存为 `contested`。这是一组有证据的充分条件，不是对古书“生多克少”的擅自计数。

### 墓绝效力

| 条件 | 输出 | 出处及处理 |
|---|---|---|
| 墓源地支被当前日或月冲 | `opened` | 随鬼入墓：“墓神被日月动爻冲破者，亦不为真”；冲的是墓源，不是拿目标月破代替 |
| 目标满足无竞争生扶充分条件，墓未被冲 | `nonbinding-strength` | “世爻旺相者非真……用神旺相者非真”；仍可待冲墓，不能写墓完全无效 |
| 目标无根或受克无潜在生扶，且墓源条件无反证 | `binding` | “惟世爻、用爻休囚被克，而又入墓者为是” |
| 动爻可能冲墓但其施力未定，或动墓源空破未定 | `conditional` | 不把“盘上有一冲”偷换成已经开墓 |
| 土遇巳，且有独立于该巳参照的支持、无竞争伤克 | `overridden-by-generation` | “土爻旺相，或得日月动爻生扶……论生不论绝”；巳不能自我证明“土已经有气” |
| 无根／受克无扶的对象逢日月或本位化绝 | `effective` | 与“衰而又绝”“休囚无气”前提绑定 |
| 跨位动绝、飞绝作用者未定，或强弱竞争 | `conditional` | 保留原典支持的作用范围，不假定来源自动有效 |

月墓也保留具体实例范围：小过之艮原文将“动墓、化墓、入月建之墓”合称三墓；概论另以日墓、动墓、化墓为三墓，不能将数量“三”机械地用作算法上限。金丑“土多生金”没有可核定的数值门槛，本轮没有发明“两个土就是土多”。

### 三合：形成与当前效力分开

| 范围／条件 | 形成裁定 | 当前效力处理 |
|---|---|---|
| 原卦三种不同局支均实际发动 | `formed` | 继续逐对象核验空破、真墓、克合冲与回头关系 |
| 内初三／外四六同时实际发动，其本位动变三支齐全 | `formed` | 不混入静位变卦投影；不混内外任意池 |
| 明动世爻与日月成完整局 | `formed` | 小过之艮直接来源；非世明动的结构推广为 `requires-scope-evidence` |
| 两动一静的原爻三支齐全 | `competing-text` | 明示两句竞争，不伪造统一门槛 |
| 全静，仅支表三支齐全 | `not-formed` | 所选增删动局剖面内不成立；不借易林半局法补证 |
| 有动而缺支 | `awaiting-member` | 同时保留成员、实际动爻和范围，不推出年月日 |
| 已形成，实际参与对象旬空／未填月破 | `awaiting-void-break` | 移动不等于当下已经填实；空破不是永久无用 |
| 已形成，有确认 `binding` 的墓 | `awaiting-tomb-open` | 结构墓／有争议墓不会自动进入此分支 |
| 已形成，无上述待成条件但有竞争生克墓绝 | `conditional` | 条件逐一可回查 |
| 已形成且选定检查没有反证 | `effective-under-selected-rule` | 不输出普遍合化，更不推出事件吉凶 |

离之坤的金局在源文仍称“合局”，而实际丑变爻为空。本报告保留“形成”与“当下待空填”两个维度，避免拿源文讨论的局象抹掉其自身等待条文。

## 古例、反例与接口

古例使用原文传统月支、日干支与实际爻画；现代测试时间仅作脚手架，未伪造古代公历日期。原始卦图显示乾之需的寅爻静而可见，但原文称“内少寅字”并待寅日；它能反驳“看到三支就当效力齐全”，仍不能消除两动一静原句。

新增 `HexagramReading.efficacy` 返回 `methodVersion`、`sourceId`、`selection`、逐对象的 `calendarStrength/vitality/activity/availability/tombs/extinctions`、逐组 `formation/efficacy`、`selectedEffect`，固定 `outcomeEstablished:false`。原有 `yongShen` 仍是候选层，其 `selectionEstablished:false` 不被改写；新层才是明确标记版本的推断。

报告最终使用 `evidenceLayout: indexed-object-decision-evidence-tuples-v2`，`indexBase:0`。所有字典属于本回执，无外部依赖：

- `objects` 七列为 `[objectPath,calendarStrength,vitality,activity,availability,tombs,extinctions]`；`calendarStrength` 三列为状态索引、支持路径索引、克制路径索引。活力、活动、可用性均指向 `decisions`。
- `decisions` 三列为 `[statusIndex,conditions,blockers]`，状态取自 `states`；条件与反证是 `evidence` 索引。
- `evidence` 两列为 `[ruleIndex,factPathIndices]`，规则取自 `ruleIDs`；`factPaths` 两列 `[rootIndex,suffixIndex]` 分别查 `pathRoots/pathSuffixes` 后连接成原始 JSON 指针。
- 墓绝参照三列为范围、来源对象路径、裁定索引；三合三列为组路径、形成裁定索引、效力裁定索引。各 `*Columns` 字段明示列名。
- 空数组、条件顺序、对象身份和全部原始事实指针保留。TS 提供展开视图；原生校验器独立重建候选与每个裁定，不信任 TS 输出的结论。

原生 `LiuyaoEfficacyEvidence` 严格核验版本、列名、整数索引、完整字典使用、路径存在及来源元数据。其独立候选重建可拒绝“同时删掉候选并重算 efficacy”的联合伪造。原生参考解读的每条证据可回查到同一回执；旧候选层和条件应期层在文案中标明层次。

完整回执在保存前使用 `CastReceiptStorage` 无损对象／条件／重复值字典，奇门另有精确日期字典；所有阅读、补问及原生验证先严格展开。保存内容自足，不包含仅限同次模型调用的 `questionFromArguments` 引用。已保存格式重试保留原字节，旧完整 JSON 继续可读。补充问答使用原保存盘的 lines、墓绝和三合结构重新生成本层，只更换问题相关取用；不重起卦、不取当前时间、不接受模型注入本层。

## 下一步全局元忌／两现：研究结论，不混入本批代码

元忌同动的明确可解分支，是“有效元神承接忌神之生、再生有气用神”这一整条链；元神入墓、衰绝、回头克、化破等必须先裁定。大过之鼎是目标无根的明确否决；屯之震（申月甲辰，子水兄为用，戌动生申、申动生子、月亦生子）是传递相生的正例。可实现的下一批应显式返回 `redirected-through-yuan` 与 `target-cannot-receive`，而非同时输出“忌克用成功”和“忌生元成功”两份无优先结论。仍不能把原文列举的有力条件当各自无条件OR：多个有力／无力条件可并存，须先建立对应化爻、墓源和目标生受能力。

两现章不支持唯一全局排序。小畜一例先以应爻月建未财判断可得，再报告辰财出空为实际应期；豫之归妹一例明确说明之所以取巳年月破，是结合前两卦共同应巳，并反问只看本卦为何不取午年。这证明缺少前占与“问吉凶还是问已知事件何时”的语境是真前提缺失。下一步可以区分事件主对象、应期对象、用户指定对象及多占比较输入；不能用“空破优先”宣称解决两现。独一角色对象与自占世爻已经可定，真正多对象处继续保留具体竞争。
