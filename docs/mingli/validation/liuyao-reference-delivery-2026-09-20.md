# 六爻依据编译：F2

本批处理F1真实DeepSeek回答中的三类错误：把实际辰酉合写成丑戌合、混用取用和应期出处、为全动爻添加暗动未决。单独六爻请求现在从原始回执生成参考报告，沿用F4的本地编译方式；不把自由撰写的候选或应期当成已核算事实。

## 返回内容与范围

- 分开呈现本卦／完整变卦、真实动爻、月日时／旬空／世应；整卦冲合只作结构信息。每个本爻、实际变爻、伏神各有自己的日月空破及生克资料。
- 回头关系、飞伏、所选七组进退、静爻日冲候选保留满足／未满足／未裁定条件。明动日冲不生成静爻暗动候选；反向作用和支合不覆盖五行关系。
- 所有取用候选分别保留对象、层级、亲属／事项依据；伴侣角色不由用户性别推断。日月、伏神、依附本位的变爻不会借用原爻的动静身份。条件应期绑定同一候选；月合、动化合的两侧及待冲支均来自对应原记录。
- 每段包含原始回执编号、JSON路径及值、来源ID／版本／原文hash。已知版本的来源URL和hash集合固定核验；条件路径、状态与所指对象的实际字段互相校验。旧F1版本完整回执可读，稀疏、未知版本、错源、错位、冲突或跨context记录不给出伪报告。
- App和实际评估器使用同一入口与编译器；混合体系问题不缩成单独六爻。繁体奇門／與参与相同方法识别；单独否定另一术数不抹掉六爻请求。解释术语或拒绝起卦的文字不进入本批参考报告路径。规则是保守有限模板，不代表覆盖任意中文意图。
- 重试使用本用户问题原回执，不重新起卦、不重复存盘。出生档案、账号隔离、取消和资料变更检查不变；没有新增本命计算。

## 验证与真实失败

11项永久测试覆盖旧F1实录、真实JSC盘、动静与本变伏、日月／伏神候选、配偶角色、空候选、缓存重试、错位／错源／条件矛盾、混合体系与繁体意图。先观察缺失实现失败；独立审查发现配偶reason遗漏、条件借位／反写状态／删项、坏来源数组、错误应期contextPath、错误回头支关系及繁体分流，均追加反例并观察RED/GREEN。

最终全量Swift Core 294项通过，含18组Node/JSC对照；ChatSession语法、native-only、diff检查通过。生产Engine未改，689项Engine结果来自本批前已通过的B2精确提交CI，不能称为本次重新运行。原生App构建仍以本批远端CI为准。独立复核通过；提交／远端结果待补。

独立最终矩阵使用同一历法时刻：4,096种爻值组合，加64全动／64全静卦×10种问题对象，共5,376份真实工具记录全部可渲染；2,446,086个引用值全部匹配，没有全动卦暗动说法。它证明本批有限交付范围，不代表所有日期、流派或事件推断正确。

最后的实际重试测试发现：编排器最多8次复用，加持久化原卦共9份回执，原先上限4会误拒绝。六爻和奇门一起修正到9；两套实际编排测试先失败再通过。独立收尾另验1／4／5／8／9份同卦全部通过，8种损坏记录全部拒绝、8种实际入口分流全部符合预期。全矩阵报告保留修正前的次数边界失败，最终次数报告独立保存，不覆盖历史。

复现脚本在`native/Engine/validation/reasoning/core-f2-{fixtures.cjs,exhaustive-fixtures.cjs,independent-probe.swift}`。从仓库根目录依次运行两个Node脚本，将样本写入`/tmp/suji-f2-*-fixtures.ndjson`；用`swiftc -parse-as-library native/Core/Sources/SujiCore/*.swift native/Engine/validation/reasoning/core-f2-independent-probe.swift -o /tmp/suji-f2-probe`编译，再传入矩阵文件运行。报告默认写到`/tmp/suji-f2-review-final-cap-report.json`；样本大文件不提交。已保存的矩阵与收尾结果为`core-f2-independent-{matrix,cap}-review.json`。

真实供应商试验存为`core-f2-results.json`，4次provider请求：成功例保留1份原卦、输出1890个字符，770个引用值由独立Python解析JSON指针逐个核对；工具失败例零回执，明确尚未取得记录。模型本次正确提取了self／wealth／收款事件／near。状态为`locally-rendered-liuyao`与`liuyao-reference-unavailable`，不记为模型自由解读正确率。使用真实Swift编排、JSC与后端handler；认证和配额为合成替身，并非部署后鉴权或SwiftUI端到端试验。

真实试验之后新增了上述损坏记录验证、意图边界修正和按reason区分取用依据的本地措辞；历史报告保留原样。初始独立失败报告另存`core-f2-independent-initial-review.json`；真实报告SHA与引用核对结果在`core-f2-live-review.json`。
