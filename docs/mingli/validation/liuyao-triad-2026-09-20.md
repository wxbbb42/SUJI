# 六爻三合成员与条件：B5b

本批实现范围是三合成员和条件的可复算记录。申子辰水、巳酉丑金、寅午戌火、亥卯未木各按生、中、墓位置列出具体对象；三支齐全、缺支、中神是否出现分别记录。重复地支保留全部对象身份，不代替缺失地支。取用、强弱、合住或合化、施力与事件结果尚未裁定。

## 原文复核的更正

此前三合研究漏读《增删卜易》六合章第十九后面的三合条文，因而将内初三、外四六动变规则误写成仅由古例推广。重新读取完整 `/19`，发现四组三合表和两个端点范围均有明确条文。补充研究 `triad-formation-source-review.json` 保存7054-byte原始正文、SHA256、摘录位置及散列；原文散列与已有六合来源一致。原研究保留，更正单独记录。

该电子本同时写有“两爻动一爻不动亦成”与“三爻若有两爻动，不成局”等不一致句子。未取得印本校勘证据，不能自行把一、两、三或虚三改成常见版本后宣称已解决。计算因此不输出统一“成局有效”的真假值。

《易林补遗》卷一直接描述前字生、中字主象、后字墓，也把申子缺辰、子辰缺申称作成局，却不认可申辰缺子。这个术语使用与“三支齐全”的集合定义不同。此处成员表的 complete 仅表示三支齐全，不能被解释成选用了某一种完整效力断法。

## 对象范围

- 可见原爻：核对六个原爻的地支，不加伏神或化爻。静卦也可能三支齐全；这只是一项表格观察，发动门槛仍有原文分歧。
- 动爻与日月：每组只检查一个实际动爻、月建、日辰。日月世的原例提供明确参照，推广到非世动爻时仅称结构观察。静态日月锚点和多个动爻自由拼池没有加入。
- 内卦动变：初、三爻须同时实际发动，只取这两爻及各自的实际化爻。外卦同理，只取四、六爻及各自化爻。完整变卦的静态二、五爻投影不能作为真实化爻，两个范围也不能合并成任意动变池。

每组保存成员自身的日月、空破冲扶 context 指针、墓绝结构参照指针和已有日冲规则指针。结构墓不等于已经入墓；日冲静爻仍是暗动/日破待审对象，不能被自动改写成明动。当前冲扰与将来冲开在原典中有不同作用，未据此生成具体日期。

## 原例和反例

离→坤 `[9,8,9,9,8,9]` 的内卦实际成员形成亥卯未三支，外卦形成巳酉丑三支；重复卯、酉分别绑定原、变对象。二、五爻静态结果投影不得进入成员。

复→谦 `[9,8,6,8,8,8]` 的子、辰与三爻实际化申组成内卦水三支，初爻化辰作为独立重复身份保留。原文仍叙述日月克世、回头克和动爻克，故三支齐全不能擦除制约条件。

革→家人 `[7,8,7,9,7,6]` 同时有外卦动变木三支与卯月、癸未日、实际动世亥的日月参照。它们是两种不同范围，分别记录。古例仅使用原文传统坐标和字面卦画，测试脚手架的现代时间戳不声称复原古代日期或验证叙述结果。
