# 奇门格局条件审查与修正

审查日期：2026-09-19；审查者：`divination_research`。范围限于现有转盘奇门、拆补三元、中五固定寄坤二且天禽随天芮的实现，不增加飞盘、置闰或其他派别。核对对象为 `native/Engine/src/qimen/data/geju.ts` 原有51条 MVP 规则。原文件笼统声称“至少2个权威源”，但未附可逐条复核的版本、页码和摘录；本次不沿用该声明。

本次保留、改正或降级为字面事实44条，删除7条未经充分核对的近似命名规则，另将八门伏吟、反吟独立列出，最终46条。识别结果表示本版传统条件或盘面事实，不代表现实事件的概率、吉凶结局或医学结论。

## 触发问题与复算

[第四轮人工审查](reasoning-round4-review.md) 已记录原始失败：`2024-02-04T04:00:00Z` 的阳遁三局、大寒上元，真实值符天任、值使生门均在震三；震三**地盘戊、天盘癸**，天盘戊在巽四。旧规则因地盘戊在震三就输出“戊击刑”，模型照抄后被核验器接受。旧“值使”格局还把开、休、生全部所在宫 `[1,3,8]` 当成值使，混淆实际值使宫3。

修正后通过本地临时 bundle 调用真实 bridge `setup_qimen`，输出值符/值使仍为天任/生门、均在宫3，**不再出现戊击刑**；“值使为三吉门”的 `palaceIds=[3]`。该盘剩余标签为：值符临三吉门、值使为三吉门、上格、丙奇遇吉门、丁与庚叠盘。复算结果保存在 `/tmp/suji-geju-review-case.json`；临时 bundle 为 `/tmp/suji-geju-review-bridge.js`。没有改写第四轮原始线上结果，也未重新发起模型调用。

## 未决限制

本次解决了可复现的方向、字段和时干上下文错误，但未穷尽全部奇门流派。六仪击刑对非值符六仪的适用、飞鸟/青龙的甲子戊限定、天禽寄干参与格局等仍是本版明确采用的口径，不能将简单诗句或另一工程表理解为所有派别一致。删除的命名格局可以在取得可靠完整条件后另行实现，不应恢复原宽泛 MVP 条件。

诗文仍为未核对纸本的在线转录；本次没有声称完成术数的实证有效性验证。旧第四轮中错误格局被模型照抄并获 accepted 的事实依然成立。源码修正和确定性用例通过不等同于已验证新模型回答质量、Supabase 登录或 SwiftUI 端到端行为。
