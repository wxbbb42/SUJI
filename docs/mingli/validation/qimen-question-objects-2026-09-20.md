# 奇门问题对象：E2a

范围：补齐既有盘面的对象身份、明确提问资料及未决状态，不新造取用或应期流派。本阶段不等于E2b应期、F解读或整个核心验收完成。

## 来源与规则边界

- `qimen-question-references-v1`明确标作`product-policy`，既有日干、时干与类别星门神映射只列参考。来源预审见[qimen-selection-source-review-2026-09-20.md](qimen-selection-source-review-2026-09-20.md)。没有把未找到的古籍句子或搜索摘要写入出处。
- `questionContext`保留用户明确的所问人、事件与远近。未知、代占视角、类别与亲属冲突分别保留；性别不替代伴侣身份。资料齐全也不自动裁定用神。
- 日干、时干各有稳定ID和对应历法字段；同干同宫不合并。甲按本柱干支的旬仪定位，干宫关系仍以原干五行计算。
- 每处地盘、地盘寄干、外宫天盘、天禽寄干、中宫留存记录都有精确`objectPath`。地盘寄干沿用既有中五固定寄坤政策，与随天禽转动的天盘寄干分开。中宫不是另一处有效天盘，不给中宫留存记录附加独立生克判断。
- 旧单宫summary/state仅保留兼容，界面改为展示全部参考候选；九宫简卡补寄干。干宫关系与九星月令分开，来源不混并。
- 应期保留`outcomeEstablished=false`、未决前提、空`triggers/dates`和未定时间单位；时空、时马仅引用现有事实。不把六爻应期移植进奇门，不用宫数推天数。
- 同一问题缓存回放保留原始起盘参数。此批没有实现跨轮追问后重新绑定候选的功能，也不声称已完成最终取用。

## 可复算与反例

1. 手算盘A：2024-02-04T04:00Z，日干戊、时干戊；地盘戊在3宫，天盘戊在4宫。两角色位置相同但ID及历法路径不同。
2. 手算盘B：2026-09-19T04:00Z，时柱甲午隐于辛，地盘/天盘在6宫；生克为甲木对乾金，不能按辛金比和。
3. 人工重排盘层：甲子日用戊、甲申时用庚；庚同时有中宫地盘、留存天盘、2宫地盘寄干与8宫天禽寄干。只有天禽寄干为有效天盘；反转数组后路径随实际索引变化，宫ID不变。此例是选择器字面向量，不冒充实际历法盘。
4. 缺天空参考时不拿地盘/中宫代替。代占、类别冲突、男女参数一致、完整上下文仍未定用等均有永久测试。
5. Core索引保留false、null与空列表；不把自由事件文本当计算事实。每个字段可反解回原回执，来源及盘层可独立引用。
6. 手算盘A中五庚固定寄坤2为地盘寄干，随天禽转到兑7为天盘寄干。坤2主地盘乙、主天盘丁，故既有格局“丁与庚叠盘”成立；不能因普通地盘乙而否认地盘寄庚。

## 验证中发现并修正

- 新字段使四份重复盘回执及核验索引超出原有预算。缩短重复说明，并无损共享对象路径前缀及内容完全相同的字段组。共享组保留全部`toolCallIDs`，原始工具消息不删改；相同与相冲突的三回执向量及逐字段还原测试覆盖身份。未扩大后端限制，未丢字段。
- 独立复核发现`candidate-not-established`只认八字状态。现对有限的明确奇门肯定句要求奇门自身所有可用回执均为false/null；无关八字候选不能授权纠错。问句、否定、转述、过去、假设、例句和冲突回执不得授权改写。它仍是有限句式检查，不是通用语义判真器。
- 真实回放暴露出地盘寄干只在格局内部隐式计算、未传给对象与解读层。增加显式`hostedDiPanGan`和`hosted-earth`；旧盘格局fallback保留。先验证字段缺失的失败测试，再验证补齐后的对象路径、盘层、显示及容量。

- 修复实际入口`ReadingIntent`：明确奇门请求先于起卦模式默认值，不再擅自替换成六爻；讨论或拒绝奇门仍不会开放该工具。已有RED/GREEN回归，使用相同问题再次回放。

- 三次报告均经过真实Swift写作/核验/工具编排与DeepSeek；认证、配额为本地替身，不是部署后的登录或SwiftUI端到端验收。协议accepted不等于事实正确。E2a接受范围只限已核验的结构和数据交付；F3须新增错宫位回归，F总体不通过。
