# 命理问答取数与拒答调试（2026-09-22）

后续32题真实矩阵已发现本报告两题范围以外的误拒与误接受；本报告不代表整体可用。以[扩展验收报告](reading-matrix-2026-09-22.md)及逐题证据为准，旧基线仍保留。

基线 `8164f25`，工作分支 `codex/fix-mingli-today-activities`。用户在 Benji 的 1.0.0 (2) 中反馈：“今天我适合拆宝可梦卡吗”需要再次明确要求计算；追问“几岁会有孩子”得到泛泛拒答，声称传统没有规则、现实建议才有用，并沿用先前的读取故障说法。我的页面能正常显示四柱和紫微。没有读取或复制用户的私人聊天数据库。

## 定位与范围

1. `TodayReadingRequest` 原先只覆盖“今天适合干什么”等完整句型。具体活动交给可选模型规划，模型可以不调用工具就结束。新增原句和中英文活动回归在修复前有 7 个失败断言。
2. 命理与倾诉共用“先理解处境、再给小事建议”的开场；大量禁止项没有配套的正向解读任务。真实原生基线复测两题均取得工具结果，但回答仍包含“谁给你报一个确定岁数，那都是编的”“比看星更有用”。所以本轮没有稳定复现用户首次缺回执的同一网络事件，确实复现了有数据却否定用户需求的内容问题。
3. 子女星、紫微子女宫、八字和紫微时间层已经实现。完整的生育应期裁定没有实现；这不是网络错误，也不证明传统术数不存在相关方法。没有为通过验收而增加无来源的生育年龄规则。

## 改动

- 对单一、明确的今日活动先执行现有今日工具，再写回答；其他日期、拒绝排盘、指定术数及关系/投资等专题继续走原规划。没有改历法和排盘算法。
- 提示版本 `suji-grounded-reading-18`：命理模式优先解释本次相关盘面、传统对应与条件；区分工具读取故障、尚未实现的解释规则和预测不确定性。子女问题先查对应星位、子女宫及需要的时间层。保留来源、流派和条件边界。
- 新增有限回复校验，纠正“本轮已经成功取数却说没有盘面”，以及把产品缺项扩大为整个传统无效、贬低用户兴趣的已观察措辞。保留真实工具错误、引用/假设、局部覆盖范围说明等反例。它不是通用语义判定器。
- 新增可重复的原生线上验收入口 `LiveReadingSessionTests` 与 `smoke-native-reading.mjs`。使用临时确认账号、真实原生密码登录、SwiftData、建档、ChatSession、已部署 Supabase 和 DeepSeek；没有网络或模型替身。常规 CI 默认跳过此测试。测试保存合成问题与资料的回执、答案和恢复结果，不记录凭据。

## 剩余限制

完整生育应期、抽卡吉凶/概率均不是本次新增能力。系统仍需有来源的解释知识与应期规则，才能在明确流派和条件下提供更深入的候选分析。当前修复解决已观察的取数漏路由和回答任务/口吻问题，不把“拿到盘面”冒充“已经实现所有事件判断”。
