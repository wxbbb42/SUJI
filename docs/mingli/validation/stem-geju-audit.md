# 天干五合、十神关系与格局反例审计

## 复现事实

输入北京时间 `1990-08-15 10:00`、女、经度120，四柱为 **庚午 甲申 壬子 乙巳**。修改前实际输出：

- 年时乙庚配对 `heHua=true`，理由只有“化神金得令”。
- 格局 `偏印格 / po / xia`，因为任意柱位乙庚配对即作庚被合去。
- 壬日的甲是食神、乙是伤官、庚是偏印。模型把乙当成枭神夺食的“食”，并不符合工具中的十神事实。

前两项来自引擎逻辑本身，不只是语言模型改写问题。现已移除单一月令即成化的判定，并在生产数据提供每一对柱位的条件和准确十神关系。

## 实际修复

1. 五合逐对保留 `positions`，区分紧邻、远隔与紧邻争合；遥隔的同名干不机械算成夹合。每一对记录月令支持与否，输出 `candidate/unresolved`，不把这些有限条件称为已成化。旧 `heHua` 在未建立成化时省略。
2. 格局的用神受合判定不再把隔位配对直接视为破格，也不因一份用神被合就删除另一份仍有效的同名透干（合一留一）。日干自身之合不作闲神合去。
3. 化气候选的“邻干”限定为月干/时干，年干不是日干的邻干；拒绝紧邻争合，拒绝任何真实比印根、额外透干比印。旧 `无根` 分档包括小于0.3的非零根，现不再把该工程档位误作根气绝对不存在。
4. 从格筛查同样保留真实比印根和透干比印；统计按柱位排除日干自身，不再按名字删掉所有同名比肩。专旺统计也修复相同的按名字漏计问题。
5. 救应检查实际相克/相生关系和柱位：不再把任意印解释成可以化掉克它的财。救应保留具体 `triggerGan`，一个对应关系不能替另一个未处理条件解围；用神自身受合也不再由不相关的忌神救应自动消除。
6. `shiShenRelations` 提供透干之间准确的来源干、目标干、十神、柱位、邻接及相克类型。壬日庚→甲为偏印制食神；庚→乙为印制伤官且年时隔位，不混为夺食。该事实仍不代表某方已被制尽或已经造成现实事件。
7. `geJuV2` 提供明确的月令用神干/十神/选择来源、`heuristic-candidate` 状态与待审条件。成败及等级字段为既有兼容规则输出，不能由名词形式误认成完成了全局古籍论证。
8. 月刃与建禄的命名必须符合日干/月支条件，非刃月透劫财不再误称月刃；阴干月劫与阳刃分开，不能辨格的比劫保留待辨标签。
9. 两支不再冒充三合/三会全局：三合含中神的两支为半合候选，缺中神为拱合候选，三会两支为三会候选；结构化输出补所需支、缺失支、完整度与 `outcomeEstablished=false`。三支齐备也不直接证明已化。
10. 流年五行对应文字统一为“扶抑参考”，不再归因给尚未自动应用的调候候选。

## 来源与限制

[《子平真诠评注》基础章](../source-texts/bazi/ziping-zhenquan/01-foundations.md)第五节明确区分“非皆合”“非皆能化”，讨论中间干、年时远隔、合一留一、本身之合及争合地位。该转录也列出远隔仍可论合的特殊例子，所以本实现把遥隔交给待审，**不宣称所有隔合绝对无效**。当前不能从月令一个布尔值证明成化。

[《子平真诠评注》食神章](../source-texts/bazi/ziping-zhenquan/37-shishen.md)区分印夺食、财解、比劫相护及调候例外，并明确须看全局配置。现新增的是可核的干、十神、柱位与生克事实，没有以存在偏印/食神就直接断成枭夺食后果。

以上仍以仓库网络转录为依据，未独立校勘印刷定本。化气、从格的保守门槛可能漏掉其他流派认可的假化/假从；这是当前候选筛查范围，不是普遍必要充分条件。清浊、强弱、专旺和格局评级仍含工程阈值；计数模型未替代全局传统解释，也未形成现实预测的实证校准。
