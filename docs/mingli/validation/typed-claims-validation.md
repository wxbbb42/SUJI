# 八字解释口径比较：类型化依据与本地回信

2026-09-19，接续 `140630f`。提示版本 `suji-grounded-reading-8`，条目协议 `suji-bazi-claims-1`。本轮针对真实 native rounds 3/4 的两个错误：把偏印格候选升为已成格，以及把土克水写成土耗水。整体命理解读准确性目标仍在进行。

## 执行边界

在“命理”模式，当前问题明确比较扶抑与格局用神时，App 与实际 Swift 评测程序使用 `BaziFrameworkReading`。当前问题只需一份 `get_domain` 的八字数据。模型规划文字不进入依据，后续模型只能提交现有条目 ID 的选择和顺序。

本地编译器将四柱、扶抑结果及其启发式性质、格局名称及候选状态、可核对的透干位置、五行关系和调候出处组织为完整条目。每条有当前工具 call ID、JSON Pointer 与原始值；规则定义另有源码/研究文件引用。五行关系使用有向枚举，以日主为参照，分别表达生我、克我、我生为泄、我克为耗。实际透干线索与取格 basis 相符时才展示；它不证明完整格局成立。缺少评分 trace 时，不把月令、帝旺或半合编成强弱算法的计算原因。

格局候选与扶抑启发式限定语由本地渲染，不能被模型删掉；没有最终自由改写步骤。模型不能添加正文、字段值或新结论。四柱、扶抑、格局、比较结论为必保条目，开头与结尾位置由本地固定。非法 JSON、未知 ID、漏核心条目、重复 ID 或附加正文均使用完整本地解释。排序请求网络失败也保留解释；取消仍中止，App 在展示前再次核对账户/出生资料 scope。

只使用当前 user entry 的已验证缓存和当前工具执行收据。出生指纹、引擎版本、提问时间或模式不同的收据不能加入；同上下文多个领域的相关八字字段冲突时，不拼凑结论。重试规划器可以不再调用工具，仍沿用本次已保存结果。导入档案的计算身份在原有导入边界已被移除。没有足够一致依据时，本地说明状态，按实际情况区分已有与缺少出生资料。

## 当前范围与后续

两份成功的同一合成命盘，不能代表全部格局或真实用户覆盖。此次边界解决的是一条明确比较路径；不含关键词的后续提问、混合问题、其他八字推断及紫微/六爻/奇门仍可能进入原有自由写作与核验流程。解释内容比纯四柱回退更有用，但条件说明仍有重复；后续应扩展有来源、有条件的条目与对话意图状态，保持限定语和依据相连。

本地渲染也不能证明底层算法、候选规则或传统预测有效性。2057 历表分歧、纸本校勘、历史时区、手工 VoiceOver、实机和发布验证继续保留原先边界，不因本轮通过而视为完成。
