# 紫微大限与流年分层验收（D2）

本批补固定大限表和独立动态层，不等于完成紫微解释验收或全部命理核心。采用现代 iztro 默认起限约定；明确区别于所读《紫微斗数全书》大限摘录，未声称各流派一致。

## 固定与动态资料

- `ZiweiPan.decadalSchedule` 在首次排本命时保存十二限，包含顺逆、虚岁区间、农历年份区间、实际本命宫名/支/干支。持久化后问答只读取，不重排本命。
- `get_ziwei_timing` 默认使用提问的固定时刻；可指定公历 `date`，明确取当日北京时间12点。实际查询时刻、民用日、完整23点换日后的计算日均返回。
- 紫微虚岁和流年在农历正月切换，完全区别于八字立春和精确起运日期。出生之前、未入首限、超出十二限分别返回状态，不编童限。
- 返回大限宫干四化、流年干四化及太岁所在本命宫；四化对象各有来源干、层级、星曜、实际本命落宫、来源ID。生年星曜及四化不改变。不包含小限、流月、流日、流曜排布或十二宫飞化网络。
