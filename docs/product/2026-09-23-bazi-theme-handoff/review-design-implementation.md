## 具体发现

### D1 · P2：继续问被长篇细读与来源推到过远的位置

**证据与反例**：第一轮 `BaziLifeThemeCard` 将唯一 `theme.continue` 放在 explanation、observation、exercise、全部来源之后。最大辅助字号下，仅单段限定就会占满多屏；用户展开“为什么这样说”后，希望马上追问，必须找到整段末尾。实际用例在这里失败，随后截图已滚进“沿着位置继续读”的旧内容，主题行动不再可见。即便失败最终证明含有测试定位问题，这一阅读阻力仍然真实存在。

**反对意见**：继续问是用户可选动作，不能把“读完所有专业依据”变成默认前置条件；但也不应把必需限定藏起来以缩短页面。

**替代方案**：保留标题、摘要与影响含义的限定常显；紧接着提供“带着这页继续问”。细读尾部重复同一动作，使用独立 UI 标识，并提供明确“收起细读”或回到摘要动作。沿用一页内渐进披露，不增加 sticky 工具条与新页面。

**验证**：普通字号/AX XXXL 深色都从摘要直接进入问道；展开来源后也能从尾部进入；实际截图同时证明限定未隐藏、按钮没有被固定 composer 或 navigation 覆盖。XCTest 用可见几何与具体区域滚动定位，不能仅靠 `exists`。

### D2 · P2：旧回答“返回册页”在视觉上没有说明会打开当前资料版本

**证据与反例**：`ChatView` 对带 `themeBinding` 的历史回答显示“返回册页 · 表达与规则”，打开的是当前资料对应的册页。版本变化说明只写在 `accessibilityHint`。用户已修改出生时刻，回到旧回答点这个按钮，会看到新盘的解释；视觉用户可能误以为是原回答依据发生了变化。

**替代方案**：按钮常显“查看当前册页”，或保留主题名并附短说明“这里打开当前资料；这条回答保留当时的依据”。历史依据仍从既有回执入口查看，不增加并行档案 UI。

**验证**：资料改变后的旧回复入口和当前报告同屏/连续截图，明确标出两者关系；归档回放依旧展示原回执，修改资料不会把新本命灌回旧回答。

### D3 · P3：来源展开的读屏焦点需要实测

第一轮实现展开依据时以 `@AccessibilityFocusState` 跳到“传统依据与适用边界”，这是合理方向；收起依据时没有和已有 `NatalReadingReportView` 一样显式回到触发按钮的 focus 恢复。代码不能证明真实 VoiceOver 顺序、转子标题以及折叠后的焦点稳定。

建议采用 trigger/source 枚举焦点，与旧页面一致，减少非视觉用户回到页顶的风险。最终仍需人工 VoiceOver，模拟器按钮可点击不替代该项。

## 暂定正向评价与边界

- 报告在本地可读，AI 入口明示由用户决定发送；草稿不被模板问题直接替换，这是有价值的控制权设计。
- 主题摘要、会改变解读含义的限定保持在细读折叠外；现代编辑练习单独标识。来源文字与原始字段二次披露，比首屏堆术语更合适。
- `SujiTheme` token 的理论 sRGB 对比：浅色 secondary/paper 4.53:1、secondary/surface 4.93:1，深色对应 8.09:1/6.89:1；主要正文和 sage 均高于 4.5:1。此计算只覆盖实色 token，不涵盖系统 material、系统 disabled 或实际渲染所有状态。
- 页面使用缩放字体、44pt 最小动作与 48pt 发送按钮。大字实际可读性仍要依新截图定案，不能只看代码。

最终评分与截图逐张结论待修改后补充。未验证真机、人工 VoiceOver、触觉、真人阅读理解、所有旧问道问题；不把小主题通过扩写成整个命理解读可用。

### D4 · P2：底部自定义导航遮挡草稿与发送按钮

**复现证据**：第二轮四个独立用例截图（handoff、过期、实际改资料、转倾诉）在相同垂直位置切掉输入框与发送圆钮的下半部。文字仍可被 XCTest 读取不代表用户可看全，圆钮部分可点击也不代表 48pt 完整目标可达。这不是只凭某张转场截图推断的缺陷。

**最小修复建议**：查 `SujiApp.mainTabs` 外层 `TabView.safeAreaInset` 与 `ChatView` 内层 composer inset 的安全区传递。让 TabView 与自定义底栏由一个父布局明确分配高度（例如稳定 TabView 和底栏成为垂直兄弟），或把共享底栏 inset 明确应用在各 tab 内容；不要给 ChatView 补某个固定设备高度的 padding。保留稳定 TabView 身份、草稿状态、键盘弹出/收起逻辑。顶部档案重建提示也必须真正占位。

**复验门槛**：键盘关闭时，输入框和完整发送圆钮都在自定义底栏上方；键盘显示时底栏隐藏且 composer 完整；普通/AX XXXL 深色、单行/多行草稿、往返册页、实际改资料重建均截图。自动验证应加入 frame 不相交条件或可点击中心与底边检查，不能仅检查 `isHittable`。
