基础页的价值不是“有几张图/多少段字”，而是**看懂我这一盘的模块结果、知道为什么与另一盘不同、需要时继续深读**。安全限制不能把这一价值降成百科；同样，个性化不能靠无条件人格判词制造。

## 与有时融合

保留奶油纸面、克制的墨色与章节节奏、原生日历体验和Profile入口。不搬测测的紫色/橙色整屏主题、人物绰号、排行榜或大块营销式解锁卡。基础页的模块图应是可读解释，专业档案的图才负责完整数据核对；两者不是“普通页纯文字、专业页才有图”。

图必须区分三种语义：传统通用关系（背景线）、当前盘确实出现的对象（标记与位置）、本规则已成立的作用（另有标签）。高亮表示被选择或有事实匹配，不能暗示力量/吉凶；未知与零值要分开。所有图有等价文本与朗读顺序；大字号用纵向摘要，不缩小字体把原图塞进屏幕。
