## DR-01 · P1：体系目录纠正了，首屏仍可能变成“先学习术语，才能读自己的结果”

**位置：**初稿 §3.1（59—89 行）、§9 的 B1—B5 顺序。

初稿先列“读懂你的八字”的通用说明，再安排日主/月令、五行、十神，最后才到格局及取用。文字说首屏应有个体解释，但没有给该内容的优先级和样稿。实现者很容易先完成五个教学章标题，用户却仍要翻很久才能看到“本盘哪里值得注意”。这与测测参考首部的个人结果锚点有明显差距。旧主题截图已经出现了大量限定与一个局部关系占住首屏；把标题换成八字术语不能解决这个问题。

**具体反例：**一份盘的格局有已审核的条件结果，日主知识却较通用。用户进入后只看到“日主是参照、这里先看月份”的课程引导，格局结果埋在第四章。另一份盘格局未决，若仍给同一套概览，只在深处说明未决，报告看起来既泛又误导。

**替代：**不改变体系内模块架构，但把“读前说明”降级为帮助，前置一个**由已审核模块生成的本盘摘要**：最多两项，明确指向所属模块，而非人格称号或生活主题。摘要按固定阅读规则选，不按凶险/稀有/命运重要性选；成立、候选、冲突各有主句模板。没有合格高层解释时显示已知结构及准确缺口，不能用通用人格补空。目录在摘要后可达，后续 B1—B5 是可选阅读顺序，不是上锁课程。

建议线框只表达合同，不伪造盘面结果：

```text
我的册页                     专业档案
八字  ∨                 本命 · 当前资料

〈该盘已审核摘要：一项成立结构及其意义〉
〈影响这项解释的关键条件，必要时常显〉
[看这项的图与解释]

本命阅读目录                  时间变化 >
日主与月令 / 五行 / 十神 / 格局 / 强弱与取用

〈第一模块：具体结果 → 一幅解释这个结果的图 → 短解释〉
读完整说明                 带着这一项问道
```

上面的折叠选择是窄屏备选，不是要求替换已有四体系选择；最终布局需原型验证。

**验法：**用至少三份真实引擎合成盘填满一条完整阅读路径，其中一份冲突/不适用；普通字号首屏无需先点击百科说明即可看到一个个体结果及必要条件，且能说清下一步读什么。用户不能仅凭“首屏出现了干支值”被判已经读到有效解释。若样稿仍只有位置与定义，就准确叫导读，不签署参考颗粒度达标。

## DR-02 · P2：删百分比仍可能留下“漂亮但不诚实”的力量图

**位置：**§3.1 五行/十神图、§4 B2/B3、§5 `diagramSemantics`。

**具体反例：**一个五行环把本盘出现的元素画成更大节点、更多高亮边，即使不写百分比，用户仍会读为力量或人格占比；十神位置图把多次出现画成更宽块，会隐含“这一特质更强”。若全盘五行生克边都一样，换盘只换日主标记，又变成百科图。

**替代：**每图明确三层：固定的关系底图、实际盘中命中的位置、规则判定结果。固定边可淡化但仍达可读对比；实有位置用文字/形状标记；候选/未决用明确状态，不能只改颜色。节点面积、线宽不编码未经确认的力量。图旁必须能读到一条当前选中关系的中文等价描述；选择变化时更新对应依据，不能只动画变色。十神的透干/支藏有分层图例，不能全堆一个计数。

**验法：**同计数不同层次、仅藏与同透、缺关系三组对照；用户能指出图中什么变了、为什么变化，且不会把面积/高亮解释成人格程度。去色、VoiceOver、最大字号下仍可取得相同信息。没有可解释的个体变化则删图或明确标为通用读图帮助，不用图的数量充当颗粒度。

## DR-03 · P2：普通页不能把流派争议和状态枚举变成一面“说明墙”

**位置：**§3.1 强弱与取用模块、§3.2 所有模块的统一顺序、§4.1 内容分级、§5 六种状态。

**具体反例：**“所选结构参考 / 固定权重扶抑 / 调候候选分别有名称与状态”若逐项平铺，再叠加不适用因素、版本、缺项、继续问边界，用户看到的是系统自我说明而不是报告。旧主题首屏实际出现了较长的限定段，证明这不是纯理论风险。

**替代：**每模块提供三个固定层级：

1. 默认：当前本盘结果 + 它在本模块里的意义 + 会改变含义的一个就近限定。完整的必要限定不能为节省屏高裁掉；若过多应重写或降级该结论。
2. 细读：为什么、相关事实的小图、分歧比较及具体未决条件。强弱与取用先用短句说明“回答的问题不同”，再让用户比较方法，不默认并列三套技术表。
3. 专业依据：规则来源、取法、计算字段和版本。普通层不输出 F/R/I/E、ready/partial 等内部词。

不是所有模块都必须六段等长，也不是每段都卡片套卡片。延续有时纸面、宋体章题、系统正文的阅读节奏：章节间留白、关系图为视觉锚点、短段落，错误/未决不变成满屏警告色。`.impeccable.md` 的温暖和自我觉察语境可指导语气，但不能再次被用来把用户要的体系报告改成练习工具。

**验法：**一份含多个未决项的样稿仍能先读到可靠内容；不适用、缺规则、计算失败三者的可见文案和动作不同。读者无需展开来源便知道候选不是结论，同时不用先读版本条款才能理解主体段落。以实际样稿判断，不设“写满字数”门槛。

## DR-04 · P2：四体系的选择前承诺需继续保留，不能在纠偏中退回四个等量“完整报告”

**位置：**§3.1 四标签、§3.3 星宿/七政差异。

初稿正文准确区分了中国二十八宿和参考中的宿曜关系，但文字线框没有保留旧方案的覆盖提示。用户切“星宿”时可能仍期待关系轮；切七政时期待恩/用/财/难图，进入后才发现只有方法导读。

**替代：**保留同一册页内的体系选择；选择列表或相邻摘要清楚表达当前实际覆盖，例如“出生星宿 · 月亮参照宿”“七政四余 · 排盘与安命”。八字的“报告”名称须由实际内容验收决定。界面无需复制长篇算法差异，也不需要大面积禁用模块；没有支持的能力不显示加载转圈或重试。专业入口携带当前体系，标题明确“八字专业档案”等，返回也回该体系。

**验法：**切换前后承诺一致；初次进入星宿的用户不会把它当宿曜关系测算。四体系的图形没有仅因为参考同色/同形便借用其他方法语义。大字号下保留覆盖文字，不能缩成四个无法辨识的等宽标签。

## DR-05 · P2：AI 入口与本地“读完整说明”必须有可预期的区别；每模块双按钮会造成另一种碎片化

**位置：**§3.1 每项的细读/继续问、§6 模块深入与跨模块咨询、§7 问道有草稿。

**具体反例：**用户只是想读完整解释，却点了每章同等强调的“继续问”，报告变成五个跳聊天的入口，离线时感觉内容被锁住。另一个用户已有关于六爻的草稿，从五行模块进入问道，若草稿被当成当前模块问题自动绑定，会产生产品语义冲突，即使底层安全校验最终能挡住。

**替代：**报告的主阅读动作始终在本地；AI 是次级动作，命名“带着这一项问道”，按需出现而不是每个事实行都放。待发送上下文紧凑显示体系、模块、当前资料和移除/返回，必要范围可展开；不能把旧主题长说明照搬成每次全屏交接卡。遇到已有草稿只附加可取消的待选上下文，不改正文、不自动发送；跨模块咨询由用户实际问题触发，不新增生活主题导航。

返回合同明确三种：细读返回模块原位置；从问道未改资料时回原模块/展开；资料已改时打开当前模块并明确“当前资料”，原答案仍能查看当时依据。无效锚点回当前体系摘要并解释，不静默跳到另一页。

**验法：**离线读完整模块、线上继续问、已有草稿、已有运行任务、移除上下文、资料变化、跨模块问题分别走通。键盘开/关下完整输入框和发送动作不被底栏盖住。旧截图显示过这个问题；新布局须在实际图中复验，不能沿用旧截图或编译成功判定。

## DR-06 · P2：图解和导航需要明确大字号的替代形态，不能只写“支持换行”

**位置：**§3 首屏标题区、§10 UI/可访问性。

**具体反例：**“我的册页 + 返回 + 专业档案”在窄屏最大辅助字号互挤；四体系标题占掉屏幕大半；五行环内部标签无法放大，只能缩小图中文字。文字全部存在于 AX 树，也不表示用户能完成返回或知道选了哪条边。

**替代：**普通字号可紧凑选择，辅助字号改纵向体系选择/当前体系菜单；专业入口可在导航下的首个操作行而不是硬塞标题同一行。图在大字时允许变成等价的关系列表或上下分层，保留图/文字切换，不要求环形不变。标题有标题语义；每个图节点/关系带对象与选中状态；展开关闭返回触发点，专业档案返回原模块，Profile 关闭回发起位置。Reduce Motion 下直接更新选中；深色不靠很淡的小字区分限定。

**验法：**最窄支持屏幕 × 最大辅助字号 × 深色；先看实际截图，再用人工 VoiceOver 走“切体系 → 读摘要与限定 → 选关系 → 细读 → 专业核对 → 返回 → 问道 → 回模块”。触控至少44pt；正常文字对比至少4.5:1，必要图形与大字至少3:1，以最终渲染色核验。自动label测试不能代替人工流程；目前没有新方案的这类通过证据。

## 推荐采纳与继续边界

| 项 | 本评审建议 | 为何不要求本轮写代码 |
|---|---|---|
| 体系→模块→图解/解释→专业档案 | 保留 | 已匹配用户纠偏，先确认计划 |
| B1—B5连贯样稿包 | 保留，并加 DR-01 的首屏/目录合同 | 需要先证明内容和页面节奏，不再先写一个局部主题 |
| 生活主题卡作为报告骨架 | 停止 | 旧代码保留不等于最终产品获批；未来只有审核合格的局部规则可迁入体系模块 |
| 四体系等长和相同解释深度 | 不采纳 | 当前能力确有差距，不能以视觉一致掩盖方法缺项 |
| 规则可靠、对用户可读二者 | 同时作为门槛 | “全部限定都写了”不能代替有用内容，参考词句动听也不能替代依据 |
| 新 UI / VoiceOver /全问道可靠性通过 | 不作判断 | 本轮只有方案和参考，旧32题18失败及新主题失败保持原判 |

设计层下一步应是**终稿纳入上述约束 → 用户确认 → 同一体系的完整差异样稿与少量关键页原型 → 独立复评 → 实现**。本评审没有授权自动推进实施，也没有要求重跑付费矩阵。
